# Proposed Paid/Unpaid Pilot Scope and Success Criteria

## Purpose
Evaluate whether FloatPath reduces manual effort and improves reproducibility of issuer free-float scenario planning versus an agreed current workflow. This document is a template, not a proposal accepted by Datindo or any issuer.

## Participants and duration
- BAE/issuer business sponsor; Corsec/operations analyst; independent reviewer; IT/security contact.
- Suggested evaluation: 2–4 weeks after security and data-rights clearance.
- Use synthetic or anonymized *authorized* historical cases unless a data protection agreement explicitly allows other data.

## Proposed pilot use cases
1. Ingest verified snapshot from agreed CSV template.
2. Reconcile and map source evidence, explicitly unknown facts.
3. Simulate transfer and new-share issuance; compare numeric outcomes.
4. Generate reviewer-friendly report with assumption and rule version trace.
5. Replay scenario independently and measure result reproducibility.

## Baseline and success metrics
| KPI | Definition | Provisional success gate |
|---|---|---|
| Calculation correctness | Golden approved fixtures matching independent expectations | 100% mandatory |
| Critical facts fabrication | Unverified numeric/asserted source accepted | 0 allowed |
| Scenario preparation time | Median analyst minutes including corrections | Target ≥30% improvement to test, not promised |
| Revision count | Number of review cycles per case | Better or no worse |
| Source trace completeness | Outputs traceable to authorized evidence | 100% fields labeled verified/unknown |
| Reviewer confidence | Structured rubric, not vibes | Agreed threshold pre-pilot |
| Security breaches | Unauthorized data exposure | 0 tolerated |

## Exclusions
No trading, shareholder servicing, official regulatory filing, approval of corporate action, legal opinions, live BEI/KSEI integration, or public republication of client data.

## Data/legal agreement prerequisites
Purpose limitation, controller/processor responsibilities, allowed source data, subcontractors/model provider, retention/deletion, breach contacts, location/deployment, access audit, IP licensing, exit/export procedure.

## Go/No-go at closing
Collect baseline and pilot evidence, sponsor approval, unresolved defects, integration effort, and willingness-to-pay discussion. A positive demo alone is not a purchasing commitment.
