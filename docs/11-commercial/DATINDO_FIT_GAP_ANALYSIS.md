## Value proposition by role
- **Business/BD:** pilot sellable add-on to issuer clients; demonstrate differentiated service value.
- **Operations:** fewer repeat calculations and missed assumptions, pending measurement.
- **IT/Security:** isolated module, BYOD, immutable scenario outputs, no privileged DB access needed for demo.
- **Legal/Compliance:** every simulation tied to rule version and evidence; unknowns visible.

## Objections and responses
1. *We have a portal.* → We are not replacing it; ask whether scenario planning and evidence provenance are already included.
2. *Our data is confidential.* → Public demo synthetic; private pilot only after data rights/security agreement; optional customer-controlled environment.
3. *Our IT can build it.* → Offer module/API pilot or benchmark, no claim that outsourcing is necessarily cheaper.
4. *Calculations belong in Excel.* → Compare reproducibility, evidence lineage, reviewer workflow, regression reliability; validate measurable benefit.
5. *Rules may change.* → Configured rule registry, source hashes, replay and required reviewer signoff.
