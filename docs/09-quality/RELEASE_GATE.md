# Release Gate / Go-No-Go

## Gate G0 Documentation
- [ ] Approved MVP scope + stories, reviewable data dictionary and API contract.
- [ ] Primary legal source identified; unsupported claims explicitly disabled.
- [ ] Synthetic fixtures complete and immutable.

## Gate G1 Calculation
- [ ] 100% signed golden numeric cases pass.
- [ ] Transfer conservation + issuance denomination invariants pass.
- [ ] Ownership eligibility always recomputed; unknown blocks legal conclusion.
- [ ] Result includes input hash and rule version.

## Gate G2 App
- [ ] End-to-end manual snapshot → comparison → memo works.
- [ ] Validation/error/unsupported states accessible and deterministic.
- [ ] No secret/real customer data in public demo.

## Gate G3 AI
- [ ] Evaluations and failure-rate report archived.
- [ ] Human verification enforced for extracted fields.
- [ ] Prompt injection and source citation tests pass.
- [ ] Manual fallback works when OpenAI unavailable.

## Gate G4 Public Demo
- [ ] Accessibility smoke pass, mobile and desktop supported.
- [ ] No unlicensed source redistribution; no Datindo logo/affiliation implication.
- [ ] Terms, simulation warning, no-login isolation.
- [ ] Video script and validation memo prepared.

## Gate G5 Confidential Pilot
- [ ] Domain/legal review of approved ruleset; contract/data license verified.
- [ ] Auth+RBAC, tenant isolation, encryption, backup & restore, retention/deletion, incident response.
- [ ] Written pilot scope and data-processing approval.

No gate is implicitly passed because docs exist. Require actual evidence/link/run results.
