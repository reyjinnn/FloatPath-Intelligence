# Value Proposition & Differentiation

## Positioning
**Not:** dashboard, official free-float certificate, shareholder ledger, trading app, legal advice or Datindo replacement.  
**Yes:** deterministic, versioned scenario engine plus source evidence and review-ready decision memo.

## Why would a buyer care?
1. Trace each scenario to a dated shareholder snapshot and supporting documents.
2. Show how shares and denominator change under different assumptions, **including when intended recipients are ineligible**.
3. Reproduce old analysis under an archived rule version.
4. Reduce manual copy-paste into briefings while keeping human reviewer in control.
5. Integrate as a module or run standalone with user-authorized records.

## Distinguishing features
- Eligibility-aware redistribution, not simplistic 10% → 15% sliders.
- Confidence/unknown/data-quality status and *fail-closed* results.
- Immutable simulation + rule + data snapshot fingerprint.
- AI document extraction with human validation and page-level provenance.
- Integration neutral deployment, no dependency on Datindo DB claims.

## Competing alternatives
Spreadsheets, legal/corporate advisers, in-house dashboards, existing BAE analytics, and issuer IR tools. Compare workflows before claiming superiority. Known BAE offering: https://sinartamagunita.co.id/pricing

## Packaging hypotheses
(A) BAE embedded module/license; (B) issuer subscription; (C) fixed-scope diagnostic pilot. Pricing **TBD after discovery**, never cite unverified Rp200–450m as actual Datindo budget.

## Proof points needed
Reference cases, rule validation, real time-on-task benchmark, security narrative, data rights clearance, optional integration contract and support SLA.
