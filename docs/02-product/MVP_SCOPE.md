# MVP Scope and Milestones

## v0.1 demonstrator — 4–6 week planning assumption
**Must:** 3–5 synthetic issuers, input + verify, one dated rule profile explicitly marked `DEMO_UNVERIFIED`, deterministic allocation/sale/issuance, 2+ comparison, provenance, memo export, baseline validations.
**Should:** PDF extraction on synthetic template + reviewer screen, AI draft memo.
**Could:** plain audit log, one historical public example *only with legal review of reuse rights*.
**Not now:** integrations, raw shareholder ID uploads, external data scraping, trading/execution, advanced corporate actions, large-scale tenant hosting, corporate brand claim.

## v0.2 pilot candidate
Authorised client-provided data, authentication, encryption, tenant isolation, upload scanning, approved regulatory source matrix, legal reviewer sign-off, incident response, retention controls, observed benchmark.

## Scope-change control
Every proposed feature: customer evidence → expected impact → legal/data dependency → effort → effect on release date; reject P2 features without proof.

## Deliverables
Working hosted demo, source repository, automated tests, reproducible fixtures, video, validation report, demo deck/one-pager, commercial pilot discovery plan.

## No-go criteria
- Unknown regulatory applicability reported as compliant.
- Shares disappear/create in a transfer or shareholder threshold crossing ignored.
- AI values accepted without review or provenance.
- Non-demo/private data visible on unauthenticated public route.
