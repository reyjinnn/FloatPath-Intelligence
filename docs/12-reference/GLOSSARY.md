# Glossary

| Term | Meaning / scope |
|---|---|
| BAE | Biro Administrasi Efek (share registrar/administrator) |
| Emiten | Issuer / listed company (confirm listed vs issuer statuses case by case) |
| CorpSec | Corporate Secretary |
| Free float | Shares meeting the applicable exchange definition (not merely retail ownership) |
| SID | Single Investor Identification; cannot infer from row count |
| Beneficial ownership | Ultimate/effective owner; may require non-public facts |
| Corporate action | Shareholder/company event affecting securities; specific approvals vary |
| Block sale | Transfer/sale of existing shares; changes holders, not total issuance |
| Private placement/new issuance | New shares; increases total and may dilute existing holders |
| Rights issue | Preemptive rights-based issuance; excluded from simple MVP scenario logic |
| Dilution | Reduced proportional stake of existing holder after issuance |
| Eligibility | Verified classification whether holding counts for relevant free float criterion |
| BYOD | Bring Your Own Data: customer lawfully supplies records |
| Provenance | Trace from value through document/snapshot/rule and reviewer |
| Golden test | Independently verified expected result used to test engine |
| Rule version | Immutable representation of effective reviewed rule set |
| SIMULATION_ONLY | Arithmetic/planning output, not an official compliance or legal conclusion |
| DPA | Data Processing Agreement |
| B2B2B | BAE licenses/embeds product and serves issuer clients |
